# Exchange-only 量子離散拡散 言語モデル (QDLM)

交換相互作用 `exp(-iθ·SWAP)` **だけ**で構成した、文字レベルの離散拡散言語モデルです。
単一量子ビットゲートは使いません。ブラウザでそのまま学習・生成できます（`index.html` を開くだけ）。

## 設計

| 要素 | 内容 |
|---|---|
| 符号化 | 1 文字 = 32 量子ビットの one-hot（単一励起）状態 `|k⟩`。語彙 `a–z 空白 . , ' ? !` |
| ゲート | 部分 SWAP `exp(-iθ·SWAP)` のみ。励起数を保存するので状態は 32 次元の単一励起部分空間から漏れない → 1 ゲート O(1) で厳密シミュレーション |
| 前向き拡散 | 確率 `1-ᾱ_t` で励起量子ビットとランダムな量子ビットを完全 SWAP する交換チャネル = 一様遷移の D3PM。`Q̄_t = ᾱ_t I + (1-ᾱ_t)/V·11ᵀ`（cosine スケジュール, T=32） |
| 逆拡散 (デノイザ) | 位置 i のノイズ文字 `|x_t^i⟩` にバタフライ配置（i ↔ i⊕2^s）の交換回路 U を作用。交換角は周囲 ±4 文字・隣接ペア・時刻 t から決まる。`p(x̂_0) = |⟨x̂_0|U|x_t^i⟩|²`（ボルン則） |
| サンプリング | 回路を測定して x̂_0 を得る → 事後分布 `q(x_{t-1} | x_t, x̂_0)` からサンプル。全位置を並列に t=T→1 |
| 学習 | `-log |⟨x_0|U|x_t⟩|²` を随伴法で微分。回路がユニタリなので逆ゲートで巻き戻し、中間状態を保存しない。疎特徴向け lazy Adam |

回路モード:
- `additive`（既定）: 交換角 θ = Σ_f W[f] を 1 本の回路（バタフライ 3 ブロック = 240 ゲート）に与える。
- `reupload`: 文脈の各特徴が自分専用の交換パルス列を順に打つ（データ再アップロード, 非可換な積）。

## 結果の目安（同梱コーパス 4.4k 文字, 評価 NLL [nats]）

| モデル | NLL |
|---|---|
| 一様分布 | 3.47 |
| 古典 log-linear（同じ特徴, softmax） | 1.69 |
| 量子 additive | ≈ 1.73–1.80 |
| 量子 reupload | ≈ 1.78–1.85 |

温度 0.7 での生成例: `to s! bes hel, earo dit ble w!por ce in here is yed ort is the`
（単語の断片 "in here is", "the" などが出る程度の小さなトイモデルです）

## 使い方

```sh
# ブラウザ: qdiffusion/index.html を開く（ビルド不要）
node qdiffusion/test_qdlm.js        # ユニタリ性と勾配チェック
node qdiffusion/train_cli.js        # CLI で学習してサンプル生成
```
